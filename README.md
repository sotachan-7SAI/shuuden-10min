# 終電まで、あと10分

2択×10回の会話ゲームです。彼女の動画（声に口を合わせたもの）は全部先に作ってあるので、選んだ瞬間に次が流れます。

遊ぶ: https://sotachan-7sai.github.io/shuuden-10min/

- スマホでもPCでも遊べます。音が出ます
- 1回遊ぶと 70MB 前後の動画を読み込みます（Wi‑Fi 推奨）
- 選ぶのは画面のボタン。PC はキーボードの A / B でも選べます
- 終わると得点が出ます
